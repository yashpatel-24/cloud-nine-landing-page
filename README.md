Cloud Nine Bakery — Figma Landing Page ☁️🥐
Project Overview
Cloud Nine is a fictional bakery app concept for ordering fresh pastries and cakes for delivery. The landing page introduces the brand, highlights its offerings, and makes it easy to explore the menu and place an order.
Target Audience
- Busy students
- Young professionals
- Families
- Customers looking for fresh bakery treats delivered to their door
Design Features
- Desktop landing page design
- Header with Cloud Nine logo, navigation, and order button
- Hero section with headline, description, pastry imagery, and calls to action
- Three feature cards highlighting freshness, ingredients, and delivery
- Bakery menu highlights
- Brand story and catering sections
- Newsletter subscription section
- Footer with navigation and social links
- Reusable header, button, and feature card components
- Shared color and typography styles
- Auto Layout used for key sections and components
Design Tools
- Figma
- Auto Layout
- Reusable Components
- Color and Typography Styles
