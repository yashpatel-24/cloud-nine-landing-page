##Cloud Nine Bakery — Figma Landing Page ☁️

## Project Overview

Cloud Nine is a fictional bakery ordering and delivery app concept. Its landing page highlights freshly baked treats and makes it easy for customers to explore the menu and order pastries.

## Target Audience

- College students
- Young professionals
- Families
- Customers looking for fresh bakery treats delivered conveniently

## Design Features

- 1440px desktop landing page
- Header with Cloud Nine logo, navigation, and order button
- Hero section with headline, description, pastry illustration, and calls to action
- Three feature cards highlighting freshness, ingredients, and convenient delivery
- Menu highlights
- Bakery story and catering content
- Newsletter section and footer
- Reusable header, button, and feature card components
- Shared color and typography styles
- Auto Layout used for key sections and cards

## Design Tools

- Figma
- Auto Layout
- Reusable Components
- Color and Typography Styles
